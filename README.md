# Crash Detection System

This project detects crashes using:
- Shock sensor
- MPU6050 accelerometer
- Arduino Nano
- SD card logging

## Features
- Real-time vibration detection
- Crash detection with LED alert
- Data logging to CSV
- Tilt and acceleration tracking

## Hardware Used
- Arduino Nano
- MPU6050
- SD Card Module
- Shock Sensor
- LED

## Output Format
timestamp,accX,accY,accZ,speed,tiltAngle,vibration
